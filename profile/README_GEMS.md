### 📌 CÁCH THIẾT LẬP TRÊN GEMINI:
1. Mở Gemini -> Menu bên trái chọn **Gem manager** (Quản lý Gem) -> **New Gem** (Tạo Gem mới).
2. Điền **Name** (Tên) và copy nội dung trong khối code của từng file dán vào ô **Instructions** (Hướng dẫn).
3. Bấm **Save** (Lưu) là xong!
